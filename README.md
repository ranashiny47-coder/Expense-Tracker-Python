# Expense-Tracker-Python
A simple Python-based Expense Tracker that allows users to enter multiple expense amounts, calculates the total spending, and displays the Total Spent. This project demonstrates basic mathematical operations, user input handling, loops, and accumulator logic in Python.
# 💰 Expense Tracker

## 📌 About the Project
Expense Tracker is a simple Python project that takes multiple expense amounts as input from the user, adds them together, and displays the total amount spent.

## 🎯 Aim
To understand mathematical operations, accumulators, and basic data processing using Python.

## 🛠️ Technologies Used
- Python
- Google Colab

## ✨ Features
- Accepts multiple expense amounts.
- Calculates total expenses using accumulator logic.
- Displays the final total spent.
- Handles invalid inputs.

## 💻 Concepts Learned
- Variables and data types
- User input using `input()`
- Type conversion using `float()`
- Loops and conditional statements
- Exception handling
- Accumulator logic: `total = total + new_expense`

## ▶️ How to Run
1. Download the Python file or open the notebook in Google Colab.
2. Run the code.
3. Enter expense amounts one by one.
4. Type `done` to finish.
5. View the final total spent.

## 📊 Example

**Input:**
- 100
- 50
- 20

**Output:**
`Total Spent: 170.0`

## 🎓 Learning Outcome
This project helped me understand how to process numerical data, perform calculations, and use accumulator logic in Python.
